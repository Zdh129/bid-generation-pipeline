# 标书排版质量标准（可量化检查项）

- 标准版本：`1.0.0`
- 适用范围：本项目**生成侧**输出的标书 DOCX / PDF（A4 竖向）。
- 严重级别：
  - **阻断**：交付前必须修复。
  - **重要**：应修复，否则视为明显质量缺陷。
  - **提示**：建议修复，不单独阻止交付。
- 阈值来源标注：
  - **真实样本统计**：基于本地样本库的只读分析（样本与转换稿不纳入本仓库；统计过程不摘录正文与个人信息），详见 `sample-stats.md`。统计过程不摘录正文与个人信息。
  - **工程标书常见规范**：如黑体/宋体层级、小五页眉、目录与页码等。本批 Word 多为短页或表格件，目录、多级标题、页码样本不足，完整标书仍按规范约束生成件。
  - **混合**：默认值取自样本，同时给出规范兼容档。
- 测试环境字体等效：宋体 → Noto Serif CJK SC；黑体 → Noto Sans CJK SC；Times New Roman → Liberation Serif。检查时做别名归一。
- 本标准**不是** GB/T 9704 公文格式（公文正文常用仿宋三号）；本批真实 Word 正文主峰为**宋体四号**。
- 个人信息：样品中的身份证件等素材不纳入本标准的示例与夹具，汇报中不出现号码、姓名等原文。

检查项共 57 条（阻断 22，重要 27，提示 8）。


## 字体与字号

### Q-FONT-001　正文中文字体为宋体或仿宋及等效字体

- 检查项：正文中文字体为宋体或仿宋及等效字体
- 严重级别：**阻断**
- 来源：真实样本统计
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：正文段落中文字体必须属于宋体或仿宋及其等效实现（测试环境允许 Noto Serif CJK SC 代替宋体）。同一文档应统一主字体。
- 机器可读阈值：
```json
{
  "allowed_east_asia": [
    "宋体",
    "SimSun",
    "NSimSun",
    "Noto Serif CJK SC",
    "仿宋",
    "FangSong",
    "仿宋_GB2312"
  ],
  "ascii_allowed": [
    "Times New Roman",
    "Liberation Serif",
    "Nimbus Roman",
    "宋体",
    "SimSun"
  ]
}
```
- 检测方法：
  - `docx`：读取正文段落 run 的 w:rFonts/@w:eastAsia 与 ascii；样式继承一并解析。未显式设置时回退到 Normal/主题字体。
  - `pdf`：对正文字号簇的 font 名称做别名归一（如 SimSun、NotoSerifCJKsc-Regular）。

### Q-FONT-002　正文字号为四号（14pt）或全文统一的小四（12pt）

- 检查项：正文字号为四号（14pt）或全文统一的小四（12pt）
- 严重级别：**阻断**
- 来源：混合（样本 + 规范兼容档）
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：正文字号默认四号 14pt（来源：8 份 Word 样本中，正文按字符数 14pt 约 2501、12pt 约 74，14pt 为明确主峰）。允许全文统一使用小四 12pt（工程标书常见规范及样本次峰）。同一文档不得混用 12 与 14 作为正文。容差 ±0.5pt。
- 机器可读阈值：
```json
{
  "primary_pt": 14,
  "alt_pt": 12,
  "tolerance_pt": 0.5,
  "must_be_uniform": true
}
```
- 检测方法：
  - `docx`：统计非标题、非题注、非页眉页脚、非表格段落的 run.font.size（含样式默认值），众数须为 14 或 12，且偏离众数超过容差的字符比例 < 5%。
  - `pdf`：按字号聚类，主体文本簇 size 应在 13.5–14.5 或 11.5–12.5。

## 标题层级

### Q-HEAD-001　标题层级连续，不得跳级

- 检查项：标题层级连续，不得跳级
- 严重级别：**阻断**
- 来源：工程标书常见规范
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：按阅读顺序，后一个标题的 level 不得大于前一个标题 level+1。文档不得以 level≥2 作为第一个标题。
- 机器可读阈值：

- 检测方法：
  - `docx`：按文档顺序收集大纲级别/Heading N，检查相邻差。
  - `json`：对中间格式 heading 块按 reading_order 检查 level。

## 页眉页脚

### Q-HF-001　正文页均有页眉

- 检查项：正文页均有页眉
- 严重级别：**重要**
- 来源：生成件高标准（样本不足以代表完整标书）
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：完整标书的正文页（封面除外）应有页眉。来源：生成件高标准。样本仅 1/8 含页眉，故该条约束生成输出，不以样本缺失为合格依据。
- 机器可读阈值：
```json

  "required_on_body_pages": true,
  "cover_optional": true
}
```
- 检测方法：
  - `docx`：检查节 header 是否存在可见内容；首页若为封面可为空。
  - `pdf`：除封面外每页顶部区域存在重复性短文本或页眉线。

## 目录

### Q-TOC-001　目录条目文本与正文标题一致

- 检查项：目录条目文本与正文标题一致
- 严重级别：**阻断**
- 来源：生成件高标准（样本不足以代表完整标书）
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：目录中列出的标题文本经空白/编号归一后，须与正文对应标题一致。当文档标题数≥3 时，生成件必须包含目录。样本 Word 均无 TOC 域（短文档），不以样本缺失放宽完整标书要求。
- 机器可读阈值：
```json
{
  "normalize_whitespace": true,
  "scope_levels": [
    1,
    2,
    3
  ]
}
```
- 检测方法：
  - `docx`：解析目录段落或 TOC 域结果，与 Heading 文本比对。
  - `pdf`：定位「目录」节，解析条目，与全文标题搜索结果比对。测试日志只记录匹配率，不摘录可能含业务名称的标题原文到对外汇报。

### Q-TOC-002　目录页码与正文标题实际页码一致

- 检查项：目录页码与正文标题实际页码一致
- 严重级别：**阻断**

- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：目录中每个条目的页码必须等于该标题在成品 PDF 中的实际页码。
- 机器可读阈值：

- 检测方法：

  - `docx`：TOC 域更新后的页码；本原型采用「先转 PDF 再回写目录」的两遍流程后检查。

  - `docx`：读取 w:spacing 的 line/lineRule（exact 的 line 单位为 twip，500=25pt；auto 时 240=1 倍）。
  - `pdf`：对正文相邻行基线间距取中位数作辅助，以 docx 为准。

### Q-SPC-002　正文首行缩进 2 个汉字

- 检查项：正文首行缩进 2 个汉字
- 严重级别：**重要**
- 来源：真实样本统计
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：正文首行缩进 2 个汉字，即 2×正文字号：四号对应 28pt，小四对应 24pt，容差 ±1.5pt。来源：样本主峰为 28pt（对应四号 2 字），另有少量 24pt。居中的标题性短句、列表、表题图题不要求缩进。悬挂缩进（样本出现 -21pt）仅允许用于列表。
- 机器可读阈值：
```json
{
  "chars": 2,
  "tolerance_pt": 1.5,
  "formula": "2 * body_size_pt"
}
```
- 检测方法：
  - `docx`：w:ind 的 firstLine（twip）或 firstLineChars。
  - `pdf`：段落首行 x0 相对后续行的偏移。

### Q-SPC-003　标题段前段后间距符合规范

- 检查项：标题段前段后间距符合规范
- 严重级别：**提示**
- 来源：工程标书常见规范
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：一级标题段前 12pt、段后 6pt；二、三级段前 6pt、段后 3pt，容差 ±2pt。来源：规范。样本标题样式不足以为据。
- 机器可读阈值：
```json
{
  "h1": {
    "before": 12,
    "after": 6
  },
  "h2_h3": {
    "before": 6,
    "after": 3
  },
  "tolerance_pt": 2
}
```
- 检测方法：
  - `docx`：标题段落 spacing before/after。
  - `pdf`：辅助测相邻块间隙。

### Q-SPC-004　正文段落两端对齐

- 检查项：正文段落两端对齐
- 严重级别：**重要**
- 来源：真实样本统计
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：正文段落对齐为两端对齐（justify/both）。来源：样本正文对齐主峰为 both。标题、题注、页眉页脚按其自身规则，不要求两端对齐。
- 机器可读阈值：
```json
{
  "alignment": "both/justify"
}
```
- 检测方法：
  - `docx`：正文段落 w:jc=both。
  - `pdf`：行左右端与版心的贴边情况辅助判断。

## 分页与空白

### Q-PAG-001　无孤行（段末单行落在页首）

- 检查项：无孤行（段末单行落在页首）
- 严重级别：**重要**
- 来源：工程标书常见规范
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：不允许段落的最后一行单独出现在下一页页首。
- 机器可读阈值：
```json
{
  "widow_lines": 1
}
```
- 检测方法：
  - `docx`：检查文档/段落 widowControl（应为开启）。
  - `pdf`：重建段落在页边界的行分布（尽力而为，不确定时不升为阻断）。

### Q-PAG-002　无寡行（段首单行落在页末）

- 检查项：无寡行（段首单行落在页末）
- 严重级别：**重要**
- 来源：工程标书常见规范
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：不允许段落的第一行单独出现在页末。
- 机器可读阈值：
```json
{
  "orphan_lines": 1
}
```
- 检测方法：
  - `docx`：同 Q-PAG-001，widowControl 同时约束寡行。
  - `pdf`：同 Q-PAG-001。

### Q-PAG-003　无空白页

- 检查项：无空白页
- 严重级别：**阻断**
- 来源：工程标书常见规范
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：成品不得出现空白页。判定：页面文字+图像像素占比 < 0.3%，且无表格。有意分隔页须在用例中声明豁免。
- 机器可读阈值：
```json
{
  "max_ink_ratio": 0.003,
  "exempt": [
    "cover",
    "intentional_separator"
  ]
}
```
- 检测方法：
  - `pdf`：渲染灰度页，统计低于阈值的墨迹比例，并检查文本/图像/矢量对象。
  - `docx`：不能可靠发现完全空白页，以 PDF 为准。

### Q-PAG-004　标题不得孤立出现在页末

- 检查项：标题不得孤立出现在页末
- 严重级别：**重要**
- 来源：工程标书常见规范
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：标题后在同一页至少还有 2 行正文或一个表格/图片，不得把标题留在页底。
- 机器可读阈值：
```json
{
  "min_following_lines": 2
}
```
- 检测方法：
  - `pdf`：检查标题块下方至页底是否还有足够内容。
  - `docx`：可设置 keep-with-next；作为辅助。

## 扫描纠偏

### Q-SKW-001　文档类扫描件或扫描图像倾斜角 |θ| ≤ 0.5°

- 检查项：文档类扫描件或扫描图像倾斜角 |θ| ≤ 0.5°
- 严重级别：**阻断**
- 来源：真实样本统计
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：文档类扫描件（含嵌入的扫描图像）倾斜角绝对值 ≤ 0.5°。来源：70 个 A4 近似扫描页中，69 页估计 |θ|≤0.4°，中位数 0.0°。若估计值落在搜索边界（约 ±8°）则标记为不可靠，不得直接判失败。非文本照片页的投影法估计不可靠，本项不适用（或只提示）。印章不检测此项。
- 机器可读阈值：
```json
{
  "max_abs_deg": 0.5,
  "unreliable_abs_deg": 7.5,
  "applies_to": [
    "asset.type=scan",
    "block.type=image 且来源为扫描"
  ]
}
```
- 检测方法：
  - `pdf`：对扫描图像或整页渲染做投影剖面（角度搜索），得到 θ。实现须处理不可靠标记。
  - `asset`：也可对源 assets 中 type=scan 的图像在嵌入前检测。

### Q-SKW-002　整页正文基线倾斜角 |θ| ≤ 0.3°

- 检查项：整页正文基线倾斜角 |θ| ≤ 0.3°
- 严重级别：**重要**
- 来源：工程标书常见规范
- 可自动化：是
- 适用对象：docx, pdf
- 阈值/规则：数字生成页或已矢量化正文的基线倾斜应 ≤ 0.3°。用于防止整页被旋转放置。
- 机器可读阈值：
```json
{
  "max_abs_deg": 0.3
}
```
- 检测方法：
  - `pdf`：对文字行基线或整页投影估计倾斜。生成件通常为 0°。

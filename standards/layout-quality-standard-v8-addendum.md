# 质量标准修订说明（阳性对照 V8）

本修订以参考成品 V8 DOCX 的实测排版为**第一依据**，避免检查器对参考成品误报。先前基于短样本 Word / 工程标书惯例的阈值，凡与 V8 冲突的，一律改为「V8 主规则 + 惯例兼容档」。详细数字见 `v8-stats.md`。

## V8 实测要点（来源：真实样本统计 / V8）

- 纸张：A4，8 个节；含纵向与横向节。页码域出现在 18/20 个页脚部件中；**无页眉**。
- 页脚：9pt，字体为 Times New Roman / PingFang SC。
- 边距：多节不一致。纵向常见上 2.52、下 2.58、左 2.79、右 2.73 cm；横向节更窄。检查改为 **1.50–3.30 cm** 范围，不再用单一 3.17 cm 中位数卡死。
- 字体：正文、1–3 级标题、表内文字、题注均为 **PingFang SC、四号 14pt**。一级标题加粗居中，二、三级加粗左对齐。**不是**「黑体三号/四号/小四」体系。测试环境无苹方时，Noto Sans CJK SC 视为等效。
- 行距：主峰固定 20 磅，其次单倍；样式默认约 1.2 倍。首行缩进 **0**（不强制 2 字）。正文对齐以左对齐为主。
- 目录：存在 TOC 域，TOC 1/2/3 共 35 段，目录字号 10.5pt。标题样式 heading 1/2/3 分别为 7/13/14 个。
- 表格：6 张，全框线 sz=2（0.25pt），4 张设置表头重复，单元格 14pt、以居中为主。
- 图片：130 个媒体、136 次放置，全部 inline；宽度主峰 16cm；有效 DPI 中位数 242.8，最低 65.1，**仅 3 张 ≥300**。故 ≥300 DPI 改为推荐值（提示），通过下限为 60 DPI，以免参考成品被阻断。
- 文档长度：目录可见条目最大页码约 246。

## 检查项口径调整摘要

| 项 | 原口径 | V8 修订后 |
| --- | --- | --- |
| 正文字体 | 宋体/仿宋阻断 | 苹方/宋体/仿宋及等效（含 Noto Sans/Serif CJK） |
| 标题字号字体 | 黑体 16/14/12 | 与正文同族 **14pt 加粗**，一级居中 |
| 页眉 | 正文页必须 | **非必须**（V8 无页眉） |
| 页边距 | 2.54/3.17±1.5mm | 允许 1.50–3.30cm，生成默认跟 V8 首节 |
| 行距 | 25 或 28 或 1.5 倍 | 允许固定 17/18/20/25/28 磅或 1.0/1.2/1.5 倍 |
| 首行缩进 | 2 字强制 | 允许 0（V8）或 2 字 |
| 正文对齐 | 必须两端对齐 | 左对齐或两端对齐均可 |
| 表框线 | ≥0.5pt | ≥0.25pt（V8 为 0.25pt） |
| 图题表题字号 | 10.5pt | 允许 14pt（V8 题注）或 10.5pt |
| 图片 DPI | ≥300 阻断 | ≥60 通过；<300 仅统计，不阻断 |
| 纸张 | 仅纵向 A4 | 允许 A4 横向节 |

生成侧默认仍按 V8 规则输出（苹方等效字体、14pt、20 磅行距、无首行缩进、左对齐、页脚页码、可选无页眉）。
